# STRING Library

Учебная C-библиотека, реализующая функциональность базовых процедур обработки строк из заголовочного файла `<string.h>` стандартной библиотеки C.

---

## 📁 Структура проекта

```text
.
├── my_string.h    # Интерфейс библиотеки (объявления функций и типы)
├── strlen.c       # Вычисление длины строки
├── strcpy.c       # Копирование строк
├── strcat.c       # Конкатенация строк
├── strcmp.c       # Лексикографическое сравнение строк
├── strchr.c       # Поиск символа в строке
└── main.c         # Модуль с демонстрационными примерами
```

---

## 🛠 Руководство по использованию функций

### 1. Вычисление длины строки: `strlen`

Возвращает количество символов в переданной строке, исключая терминальный нуль-байтовый символ (`\0`).

* **Прототип:** `int strlen(const char *string);`
* **Особенности:** В текущей реализации предусмотрена проверка на `NULL`. Если передан нулевой указатель, функция возвращает `-1`.
* **Пример применения:**

```c
#include <stdio.h>
#include "my_string.h"

int main(void) {
    const char *text = "Hello, World!";
    int length = strlen(text);
    
    if (length != -1) {
        printf("Длина строки: %d байт\n", length);
    }
    return 0;
}
```

---

### 2. Копирование строки: `strcpy`

Переносит последовательность байтов из строки-источника `source` в буфер назначения `destination`, включая терминатор `\0`.

* **Прототип:** `char *strcpy(char *destination, const char *source);`
* **Возвращаемое значение:** Указатель на начало буфера `destination`.
* **Требования к безопасности:** Вызывающий код должен гарантировать, что объем выделенной памяти в `destination` достаточен для размещения `source` во избежание выхода за пределы массива (Buffer Overflow).
* **Пример применения:**

```c
#include <stdio.h>
#include "my_string.h"

int main(void) {
    const char *src = "Data payload";
    char dest[32]; // Гарантируем достаточный размер буфера

    strcpy(dest, src);
    printf("Скопированные данные: %s\n", dest);
    return 0;
}
```

### 3. Конкатенация строк: `strcat`

Выполняет объединение строк, добавляя содержимое `source` в конец `destination`. Символ `\0` в `destination` перезаписывается первым символом `source`.

* **Прототип:** `char *strcat(char *destination, const char *source);`
* **Возвращаемое значение:** Указатель на результирующую строку `destination`.
* **Требования к безопасности:** Целевой буфер должен содержать корректно терминированную строку и располагать достаточным запасом памяти для приема новых данных.
* **Пример применения:**

```c
#include <stdio.h>
#include "my_string.h"

int main(void) {
    char path[256] = "/var/log/";
    const char *filename = "system.log";

    strcat(path, filename);
    printf("Итоговый путь: %s\n", path);
    return 0;
}
```

### 4. Сравнение строк: `strcmp`

Выполняет посимвольное лексикографическое сравнение двух строк на основе ASCII-кодов их элементов.

* **Прототип:** `int strcmp(const char *s1, const char *s2);`
* **Возвращаемое значение:**
  * `0` — строки эквивалентны.
  * Значение `> 0` — первый отличающийся символ в `s1` имеет больший ASCII-код, чем в `s2`.
  * Значение `< 0` — первый отличающийся символ в `s1` имеет меньший ASCII-код, чем в `s2`.
* **Пример применения:**

```c
#include <stdio.h>
#include "my_string.h"

int main(void) {
    const char *str1 = "apple";
    const char *str2 = "banana";

    int result = strcmp(str1, str2);

    if (result == 0) {
        printf("Строки идентичны\n");
    } else if (result < 0) {
        printf("Строка '%s' лексикографически меньше '%s'\n", str1, str2);
    } else {
        printf("Строка '%s' лексикографически больше '%s'\n", str1, str2);
    }
    return 0;
}
```

### 5. Поиск символа: `strchr`

Осуществляет поиск первого вхождения указанного символа `ch` в строке `str`.

* **Прототип:** `char *strchr(char *str, int ch);`
* **Возвращаемое значение:** Указатель на искомый символ в строке. Если символ не найден, функция возвращает `NULL`.
* **Особенности:** Функция также позволяет искать терминальный нулевой символ `\0`.
* **Пример применения:**

```c
#include <stdio.h>
#include "my_string.h"

int main(void) {
    char str[] = "user@domain.com";
    int target = '@';

    char *match = strchr(str, target);

    if (match != NULL) {
        printf("Символ '%c' найден по адресу: %p (индекс %ld)\n", 
               target, (void *)match, match - str);
    } else {
        printf("Символ не найден\n");
    }
    return 0;
}
```
